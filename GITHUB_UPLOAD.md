# GitHub upload steps

1. Open https://github.com/new.
2. Use repository name `Checkpoint-Aware-GPU-Scheduler`.
3. Use description `C++ and PyTorch scheduler that checkpoints training to serve latency-sensitive GPU jobs.`
4. Select Public.
5. Leave Add README, Add .gitignore, and Add license disabled because they are included here.
6. Create the repository.
7. Choose `uploading an existing file` or `Add file > Upload files`.
8. Extract the supplied ZIP and open the inner `Checkpoint-Aware-GPU-Scheduler` folder.
9. Select every item inside that folder and upload them. `README.md` must be at the repository root.
10. Use commit message `Add checkpoint-aware GPU scheduler and five-run benchmark`.
